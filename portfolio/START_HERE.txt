🚀 GET STARTED IN 3 STEPS:
═════════════════════════════════════════════════════════════════════════════

STEP 1: Test Locally (1 minute)
────────────────────────────────────────────────────────────────────────────
Open Terminal/Command Prompt and run:

    cd /Users/Narendra/Developer/iOS\ Development\ \(\ Swift\ \)/chronos/portfolio
    open index.html

Your website will open in your default browser!


STEP 2: Customize Your Info (5 minutes)
────────────────────────────────────────────────────────────────────────────
Edit index.html and replace these placeholders:

1. Find "https://github.com" (appears 3 times)
   → Replace with: https://github.com/YourUsername/chronos

2. Find "your-email@example.com"
   → Replace with: your.actual@email.com

3. Find "https://linkedin.com/in/yourprofile"
   → Replace with: https://linkedin.com/in/YourActualProfile


STEP 3: Deploy to Internet (2-5 minutes)
────────────────────────────────────────────────────────────────────────────
Choose ONE option:

OPTION A: GitHub Pages (Recommended)
────────────────────────────────────────────────────────────────────────────
1. Create a new repository on GitHub: "chronos-portfolio"
2. Open Terminal in portfolio folder and run:

    git init
    git add .
    git commit -m "Add Chronos portfolio website"
    git branch -M main
    git remote add origin https://github.com/YourUsername/chronos-portfolio.git
    git push -u origin main

3. Go to repository Settings → Pages
4. Select main branch and save
5. Your site will be live at: https://YourUsername.github.io/chronos-portfolio


OPTION B: Netlify (Fastest)
────────────────────────────────────────────────────────────────────────────
1. Go to netlify.com and sign up
2. Drag & drop the entire "portfolio" folder
3. Your site is live instantly!
4. Get custom domain: Netlify → Site Settings


OPTION C: Vercel (Excellent Performance)
────────────────────────────────────────────────────────────────────────────
1. Go to vercel.com
2. Create Git repository first
3. Import repository to Vercel
4. One-click deploy!
